# LogicLab 版本留档

每个版本按架构分目录存放，文件是**封装好的单文件 exe**（自解压、免安装、双击即用）。

```
releases/
├─ X86/     x64（Intel / AMD 64 位）
└─ ARM64/   ARM64（骁龙 X 系列等 Windows on ARM）
```

命名规则：`LogicLab-<版本号>-<架构>.exe`

## 版本历史

| 版本 | 日期 | 主要变化 |
|---|---|---|
| 0.1.0-beta2 | 2026-09-10 | 新增设计规则检查（多驱动 / 位宽 / 悬空 / 组合环）、参数面板由 core 描述自动生成、5 个内置示例电路、启动即载入示例；回归测试扩到 36 项 |
| 0.1.0-beta1 | 2026-09-10 | 首个可运行版本。core 按 v3 规格重写（1 tick 双缓冲语义）、自动走线、自绘画布、31 种组件、工程存档 |

## 运行说明

1. 按机器架构选目录（不确定就用 X86）
2. 双击 exe，首次运行会解压运行时到 `%LOCALAPPDATA%\LogicLab\runtime`（约 1~2 秒），之后走快路径
3. 可在命令行加参数，例如 `LogicLab-x64.exe --headless --quit-after 120`

## 操作速查

| 操作 | 方式 |
|---|---|
| 载入示例 | 左侧"示例电路"下拉 |
| 放置元件 | 左侧库中点击，再点画布 |
| 连线 | 从一个引脚拖到另一个引脚 |
| 选中 / 拖动 | 左键点元件 / 按住拖动 |
| 开关翻转 | 单击开关元件 |
| 旋转 | 选中后按 R |
| 删除 | 选中后按 Delete |
| 剪断导线 | 右键菜单暂未做；可用 Delete 删元件后重连 |
| 平移 | 右键或中键拖动 |
| 缩放 | 滚轮 |
| 居中显示 | 按 C |
| 单步 | 空格或底部"单步" |
| 运行 / 暂停 | 底部按钮（右侧滑块调速） |
| 改进参数 | 选中元件后在右侧面板改（位宽、输入数、时钟周期、RAM 深度…） |
| 检查电路 | 左侧"设计规则检查 (DRC)"按钮 |
| 保存 / 载入 | 左侧按钮（存到 `user://logiclab_project.json`） |

## 已知限制

- 撤销 / 重做尚未实现
- 波形查看器与 Verilog 导出尚未实现
- 组合反馈（如 SR 锁存器）会被 DRC 报为错误——这是**正确行为**，导出 Verilog 前需要改造成带时钟的形式
