# LogicLab 版本留档

每个版本按架构分目录存放，文件是**封装好的单文件 exe**（自解压、免安装、双击即用）。

```
releases/
├─ X86/     x64（Intel / AMD 64 位）
└─ ARM64/   ARM64（骁龙 X 系列等 Windows on ARM）
```

命名规则：`LogicLab-<版本号>-<架构>.exe`

> 版本号用 **Checkpoint** 而不是 alpha/beta：项目整体处于测试期，检查点语义中性、可无限延续，
> 不会出现「beta 五连发」这种尴尬。

## 运行说明

1. 按机器架构选目录（不确定就用 X86）
2. 双击 exe，首次运行解压运行时到 `%LOCALAPPDATA%\LogicLab\runtime`（约 1~2 秒），之后走快路径
3. 可加命令行参数，例如 `LogicLab-x64.exe --headless --quit-after 120`

| 操作 | 方式 |
|---|---|
| 载入示例 | 左侧「示例电路」下拉 |
| 放置元件 | 左侧库中点击，再点画布 |
| 连线 | 从一个引脚拖到另一个引脚（自动避让，不会误连） |
| 选中 / 拖动 | 左键点元件 / 按住拖动 |
| 开关翻转 | 单击开关元件 |
| 旋转 / 删除 | 选中后按 R / Delete |
| **撤销 / 重做** | **Ctrl+Z / Ctrl+Y**（或左侧按钮） |
| **插入网络标签** | 按 **L**（同名标签自动相连，无需拉线） |
| 编辑网络标签 | 双击标签 |
| 查看某点信号 | 鼠标悬停在元件或引脚上，显示类型名/实例名/当前值 |
| **插入文本注释** | 按 **T**（在鼠标位置插入，随即弹出输入框） |
| **编辑注释** | 双击注释 |
| 平移 / 缩放 / 居中 | 右键或中键拖动 / 滚轮 / C |
| 单步 / 运行 | 空格 / 底部按钮（右侧滑块调速） |
| 改参数 | 选中元件后在右侧面板改（位宽、输入数、时钟周期、RAM 深度、Splitter 分段…） |
| 改实例名 | 右侧面板「实例名」输入框（层级调试与导出用） |

| 保存 / 载入 | 左侧按钮（存到 `user://logiclab_project.json`） |
| **进入子电路** | **双击实例**（或选中后按 **E**） |
| **返回上一层** | 按 **B**，或点顶部面包屑 |
| **新建 / 改名 / 删除图纸** | 顶部导航条上的按钮 |

## 重要行为

**编辑即重置仿真**（规格 ADR-23）：任何编辑操作（放置、连线、改参数、旋转、删除…）
生效后，仿真会**整体回到上电态**、tick 归零。这是有意设计——否则撤销之后寄存器值
会变成未定义，调试时会被误导。拨开关（运行期交互）**不**触发重置。

## 已知限制

- Verilog 导出、测试台（CSV 激励）、仿真 checkpoint 尚未实现
- 复制粘贴、对齐吸附尚未实现
- 波形同时最多观察 64 条网络、4096 拍
- 组合反馈（如 SR 锁存器）会被 DRC 报为错误——这是**正确行为**，导出 Verilog 前需要改造成带时钟的形式
